# wash-investment-urgency-index
This project builds a cross-national WASH Investment Urgency Index using household survey data from the DHS Program API and World Bank API. The analysis quantifies marginal health returns to water, sanitation, and hygiene investment across countries to support prioritization by NGOs and development institutions. Tools: Python, Pandas, scikit-learn, statsmodels.
Current Status: EDA phase — data integration, cleaning, and exploratory analysis complete. Index construction in progress.
